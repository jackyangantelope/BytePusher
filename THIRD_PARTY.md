# Third-party code and provenance

- The [BytePusher specification](https://esolangs.org/wiki/BytePusher) defines VM behavior; no emulator implementation or third-party program was imported. The VM, pager, state backend, 480 MHz clock hook, nonblocking logger, and test-program generators were written in the development workspace. The original port code is BSD-3-Clause; the notice is in `LICENSES/jack-green-ports-BSD-3-Clause.txt`.
- [PicoPlus-devel/pico_shared](https://github.com/PicoPlus-devel/pico_shared), commit `df683bf00ff95e1ceda88f132bbf72f8cc7cadb0`: minimal public source subset under `deps/pico_shared/`, GPLv3 in its `LICENSE`. Its pico_fatfs driver retains its own `drivers/pico_fatfs/LICENSE`; FatFs notices remain in source.
- `deps/bytepusher_hdmi/` derives from the HDMI source in that same `pico_shared` project, with this port's HSTX startup/reset and diagnostic changes. It is not an unmodified upstream snapshot. GPLv3 is retained in `deps/bytepusher_hdmi/LICENSE`. `platform/wave1/hdmi/bytepusher_hdmi.c` adds the HDMI audio packet path, and `platform/wave1/hdmi/jack_di_queue.c` adds a static queue.
- The Fruit Jam platform runtime and loader-partition helper are adapted from [jackyangantelope/gamate-public-release](https://github.com/jackyangantelope/gamate-public-release) commit `4e61e6e4cb304e2fa342862af4d47413782d72f7`, with Fruit Jam USB, SD, video, PSRAM, and clock integration. The original BSD-3-Clause notice is retained in `LICENSES/jack-green-ports-BSD-3-Clause.txt`. The combined firmware is GPLv3.
- Pico SDK and Pico-PIO-USB are external build dependencies and are not copied into this repository. Follow their own upstream licenses.
